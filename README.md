## 🚀 О ПРОЕКТЕ

**InfinityBrowser** — это полноценный веб-браузер, написанный на Python с использованием QtWebEngine. Он включает более 50 функций, которые делают его мощным и удобным инструментом для серфинга в интернете.

> ⚠️ **Важно:** Это демонстрационная версия, которая находится в разработке. Не гарантирует полную безопасность и анонимность.

## 🛠️ УСТАНОВКА

### Требования
- Python 3.8 или выше
- Git (опционально)

### Установка зависимостей

```bash
# Клонируем репозиторий
git clone https://github.com/mrfoggydev-wq/InfinityBrowser.git
cd InfinityBrowser

# Создаём виртуальное окружение (рекомендуется)
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Устанавливаем зависимости
pip install -r requirements.txt
